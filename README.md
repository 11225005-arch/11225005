# 人工智慧期中報告：Google Colab 與 MNIST 手寫數字辨識

## 一、專題簡介

本專題依據 Google Colaboratory 教學文章，學習如何使用雲端環境執行 Python 程式，並透過 MNIST 手寫數字資料集建立人工智慧神經網路模型。

實作內容包含 Google Colab 環境設定、GPU 測試、Google Drive 掛載、Python 程式執行、MNIST 資料前處理、模型訓練、測試與結果視覺化。

## 二、開發環境與工具

- 開發平台：Google Colaboratory
- 程式語言：Python 3
- 深度學習框架：TensorFlow 2.21.0 / Keras
- 資料處理：NumPy
- 圖表繪製：Matplotlib
- 硬體加速器：NVIDIA Tesla T4 GPU
- 版本與成果管理：GitHub

## 三、MNIST 資料集介紹

MNIST 是常見的手寫數字辨識資料集，包含數字 0 至 9 的灰階圖片。

- 原始訓練資料：60,000 張
- 原始測試資料：10,000 張
- 圖片尺寸：28 × 28 像素
- 分類類別：10 類（0～9）

本次將原始訓練資料的 20% 作為驗證資料：

| 資料用途 | 圖片數量 |
| --- | ---: |
| 訓練集 | 48,000 |
| 驗證集 | 12,000 |
| 測試集 | 10,000 |
| 總計 | 70,000 |

## 四、資料前處理

將圖片像素值由原始的 0～255 除以 255，轉換至 0～1 的範圍。

```python
x_train_normalized = x_train.astype("float32") / 255.0
x_test_normalized = x_test.astype("float32") / 255.0
```

此處理有助於神經網路更穩定地進行訓練。

## 五、神經網路模型架構

本次使用全連接神經網路（MLP）進行 MNIST 手寫數字分類。

| 模型層 | 功能 | 參數數量 |
| --- | --- | ---: |
| Flatten | 將 28 × 28 影像展平成 784 個數值 | 0 |
| Dense（128, ReLU） | 學習數字影像特徵 | 100,480 |
| Dense（10, Softmax） | 輸出 0～9 的分類機率 | 1,290 |
| **合計** | | **101,770** |

模型訓練設定：

- Optimizer：Adam
- Loss：Sparse Categorical Crossentropy
- Epochs：5
- Batch Size：128
- Validation Split：20%

## 六、模型訓練結果

模型完成 5 個回合的訓練，訓練與驗證準確率如下：

| 回合 | 訓練準確率 | 驗證準確率 |
| --- | ---: | ---: |
| 1 | 89.21% | 94.18% |
| 2 | 94.74% | 95.68% |
| 3 | 96.14% | 96.21% |
| 4 | 97.02% | 96.29% |
| 5 | 97.54% | 96.88% |

第 5 回合：
- 訓練損失：0.0862
- 驗證損失：0.1057

從訓練曲線可以看出，隨著訓練回合增加，模型準確率整體上升，損失值整體下降。目前沒有明顯的持續性過度擬合跡象，但仍需更多實驗才能進一步確認。

## 七、最終測試結果

使用未參與模型訓練與驗證的 10,000 張測試圖片進行評估。

| 評估項目 | 結果 |
| --- | ---: |
| 測試圖片數量 | 10,000 |
| 測試準確率 | **97.02%** |
| 測試損失 | 0.0971 |
| 正確辨識數量 | 9,702 |
| 錯誤辨識數量 | 298 |

本次模型在獨立測試資料上達到 97.02% 的準確率，顯示模型已具備良好的手寫數字辨識能力。

## 八、AI 預測結果分析

本專題另選取測試集前 10 張圖片進行預測展示。

- 正確預測：9 張
- 錯誤預測：1 張
- 展示樣本正確比例：90%

其中一張真實數字為 5 的圖片，被模型誤判為 6，顯示字跡形狀差異可能影響辨識結果。

須注意：10 張圖片的展示比例不代表整體模型效能，正式模型準確率應以 10,000 張測試圖片的 97.02% 為準。
